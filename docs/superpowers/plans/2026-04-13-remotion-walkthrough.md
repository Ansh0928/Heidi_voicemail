## Goal

A 105-second programmatic demo video showing how raw voicemails become
actionable items — what's automated vs human, and how this fits into a
clinic's morning workflow. Renders to MP4 via Remotion. Voiceover via
ElevenLabs. Captions synced from ElevenLabs word-level timestamps.

---

## Scope (ACCEPTED)

- 6 scenes, ~105 seconds, 3150 frames @ 30fps
- Full Remotion scenes (React components, not screen recording)
- ElevenLabs TTS voiceover (warm, professional voice)
- Captions track baked into render from ElevenLabs timestamps
- 16:9 (1920×1080) only

## NOT in scope

- Vertical cut (9:16) — deferred, Remotion makes it easy to add later
- Remotion Player embed in Next.js app — deferred
- Background music — not decided, user can layer in post if wanted
- Live app screen recording — using React scenes instead

## ElevenLabs Setup

1. Sign up at elevenlabs.io (free tier: 10k chars/month — this script is ~650 chars, well within free)
2. Select voice: "Rachel" (warm, professional) or try "Aria"
3. Settings: Stability 0.5, Similarity Boost 0.75, Style 0.2
4. Generate → Download MP3
5. To get timestamps: use ElevenLabs API with `with_timestamps: true`
   OR use the free alternative: Whisper locally:
   ```bash
   bunx openai-whisper voiceover.mp3 --output_format json
   ```
   This produces word-level timestamps you can use directly.

## Key Remotion Patterns Used

```typescript
// Spring entrance (most elements)
const frame = useCurrentFrame()
const { fps } = useVideoConfig()
const opacity = spring({ frame, fps, from: 0, to: 1, durationInFrames: 20 })

// Interpolate (counter animation)
const count = interpolate(frame, [0, 60], [40, 8], {
  extrapolateRight: 'clamp'
})

// Sequence (scene composition in Root.tsx)
<Sequence from={1350} durationInFrames={900}>
  <Dashboard />
</Sequence>

// Audio sync
<Audio src={staticFile('voiceover.mp3')} />
```
